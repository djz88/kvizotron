# C4 Results Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A run can show a public scoreboard (hidden, live, after the end) with one official attempt per participant, anonymised live names, three revision modes and a projector view; the admin sees statistics of a run, a comparison of a quiz's runs, and a sortable attempts table.

**Architecture:** A new plugin `results.local` behind a new port `result_view` (`ResultViewPlugin`) holds the pure rules: which attempt is official, the order and ties, score summaries. It declares the scoreboard settings in its manifest. The domain (`app/domain/results.py`, `app/domain/run_stats.py`) snapshots the settings onto `QuizRun.results_json`, reads attempts, builds the board and statistics, and caches the public board for a few seconds. The API adds the public scoreboard page with an HTMX fragment polled every 15 s, a projector view, the run-page sections and the merge action.

**Tech Stack:** Python 3.15, Django 6.1, Jinja2, HTMX, SQLite WAL, plain JS (no build), pytest.

**Spec:** `docs/superpowers/specs/2026-11-08-c4-results-design.md`

- Anonymous label default per language: `Hráč NN` / `Player NN` / `Гравець NN`; `NN` is replaced by the number, a label without `NN` gets `" "` and the number appended.
- Public board cache: `BOARD_CACHE_SECONDS = 5`, key `kvz-board:<run id>:<locale>`, Django's default cache. Poll interval 15 s.
- No e-mail, participant id, attempt id or cookie value in public HTML, a log, an audit `details` or a URL.
- Test runs never appear in a board or statistics; `QuizRun.objects` already hides them, queries on `Attempt` filter `run__kind="normal"`.
- Every text in cs, en, uk via `make messages` (admin texts cs and en); a run is `běh` / `run`, never `kolo`.
- Phone width, light and dark, keyboard; no build step; scripts are files in `app/api/assets/` listed in `rendering.SCRIPTS` (CSP forbids inline).
- Plugin imports only `app.contracts`. New ADR is 0051, new AC from AC-81; each new AC and AC-06, AC-16, AC-18, AC-70 is named by a test docstring (`tests/test_docs.py`).

## Review Focus

1. The same browser plays three times on a run with repeating allowed and a visible scoreboard: one row, the best (or first) attempt; equal scores take the earlier. Tested in Task 3.
2. The admin turns the scoreboard on mid-run: earlier attempts without a participant are each their own anonymous row, and numbers of existing rows do not change when later ones arrive. Tested in Task 3.
3. A board with no submitted attempt, and a revision with max 0: empty table with a message, percent 0, no division error. Tested in Tasks 1 and 3.
4. An open live board when the admin switches it to hidden, or a photo waits for grading: the next poll shows the reason and keeps polling; an ended run with nothing pending stops polling. Tested in Task 4.
5. An anonymous label with `<b>`, without `NN`, or empty in one language: escaped, number appended, default of that language used. Tested in Tasks 2 and 3.

- Produces in `app.contracts`:
  - `ScoreEntry(key: str, attempt_id: str, name: str, score: Decimal, max_score: Decimal, submitted_at: datetime, duration_ms: int | None)`, frozen. `key` is the participant id, or `"a:" + attempt id` without a participant.
  - `RankedRow(rank: int, entry: ScoreEntry)`, frozen.
  - `ScoreSummary(count: int, average: Decimal | None, median: Decimal | None, lowest: Decimal | None, highest: Decimal | None, bands: tuple[int, ...])`, frozen; `bands` has 10 counts.
  - `ResultViewPlugin` protocol: `id`, `version`, `pick_official(entries: Sequence[ScoreEntry], rule: str) -> ScoreEntry`, `rank(entries: Sequence[ScoreEntry], rules: Mapping[str, str], seed: str) -> list[RankedRow]`, `summarize(scores: Sequence[Decimal], max_score: Decimal) -> ScoreSummary`.
- Plugin registered as `registry.register("result_view", "local", plugin, "results.local")`; manifest id `results.local`, `provides: ["result_view"]`, `settings` = the twelve with labels, value labels and help (help on visibility: "A visible scoreboard remembers each browser with a cookie, so one person is one row."; on duration items: "Needs the data profile that keeps times.").
- Rules: `pick_official` best = highest score, then earlier `submitted_at`, then `attempt_id`; first = earliest `submitted_at`, then `attempt_id`. `rank` orders by score descending, then the second sort ascending (`submitted_at`, or `duration_ms` with `None` last), then the tie policy: `shared` gives equal ranks to equal (score, second key) and shows them by `submitted_at`, `key` (1, 1, 3); `earlier` by `submitted_at`, then `attempt_id`; `random` by `sha256(seed + key)`. `summarize`: average and median rounded to 2 places, band = `min(9, int(score / max * 10))`, band 0 when max is 0; empty input gives count 0 and `None`s.

### Task 3: The board projection, merge and own place

**Files:**
- Modify: `app/domain/results.py` (projection part)
- Test: `tests/domain/test_results_board.py`, `tests/conftest.py` (autouse fixture `cache.clear()`)

**Interfaces:**
- Consumes Task 1 plugin through `registry.get("result_view", "local")`, Task 2 `of`, `revision_mode`, `anonymous_label`.
- `BoardRow(rank: int, label: str, score: Decimal, max_score: Decimal, percent: int, submitted_at: datetime, duration_ms: int | None, mine: bool)`, `Table(revision_no: int | None, max_score: Decimal, rows: list[BoardRow])`, `Board(tables: list[Table], hidden: str | None, columns: tuple[str, ...], final: bool)`, frozen dataclasses. `hidden` is one of `"hidden"`, `"after_end"`, `"pending"`, `"archived"`, or `None`. `columns` lists the switched-on of `score`, `percent`, `time`, `duration` (`duration` only when the profile is `detailed`). `final` is true when the run is `CLOSED` or `ARCHIVED` and nothing is pending.
- `results.board(run: QuizRun, *, audience: Literal["public", "admin"], locale: str, viewer: Participant | None = None) -> Board`.
  - Candidates: attempts of the run with status `SUBMITTED`, `submitted_at` and `score` set (`SWITCHED`, `ABANDONED`, `IN_PROGRESS` and `PENDING_GRADING` never count). Grouped by participant; an attempt without a participant is its own group.
  - Tables: `separate` → one per revision the run used (`RunRevision`), newest first, max from `RunRevision.max_score`, official chosen within each table; `latest` → attempts on `run.current_revision` only; `merged` → one table.
  - Public visibility: `hidden` setting → `"hidden"`; `after_end` while `OPEN` → `"after_end"`; `ARCHIVED` without `archived_results=on` → `"archived"`; any `PENDING_GRADING` attempt of the run → `"pending"`. A hidden board has no tables. The admin audience is never hidden and always shows names.
  - Names: number = 1-based position of the group in the order of (participant `created_at`, or attempt `started_at` without a participant; then id). Public and `OPEN` and `anonymised` → every label is the anonymous label; otherwise the nickname, and a group without one is the anonymous label, or under `unlisted` left out of the rows after ranking (ranks keep their gaps).
  - `mine` is true for the viewer's participant group only.
  - Public boards are cached under `kvz-board:<run id>:<locale>` for `BOARD_CACHE_SECONDS` before `mine` is applied.
- `results.place_of(attempt: Attempt) -> tuple[int, int] | None`: the rank of the attempt's group and the number of ranked groups in its table, uncached, counting unlisted groups; `None` when the public board is hidden or the attempt's group has no official attempt yet.
- `results.is_public(run: QuizRun) -> bool`: the public board of a normal run is not hidden.
- `results.merge(run: QuizRun, *, admin_id: str) -> None` raises `results.MergeRefused(code)` with `"one_revision"` (fewer than two `RunRevision` rows) or `"max_differs"`; sets `merged` and audits `run.revisions_merged`. `results.unmerge(run: QuizRun, *, admin_id: str) -> None` clears it and audits `run.revisions_unmerged`.
